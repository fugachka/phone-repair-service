## Описание проекта

Веб-приложение для автоматизации работы мастерской по ремонту мобильных устройств. Система поддерживает разграничение ролей (клиенты, мастера, администраторы), ведение каталога услуг/моделей, оформление заказов и отслеживание статусов ремонта.

## Стек технологий

-   **Платформа:** .NET (ASP.NET Core MVC)
-   **Язык программирования:** C#
-   **База данных:** MySQL, Entity Framework Core
-   **Тестирование:** NUnit
